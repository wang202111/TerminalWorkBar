添加任务

没有合适的入口？直接新建，保存后回到这里，无需切换到终端页。

任意层级都能有自己的终端和记录，也能继续添加子级。修改「上级节点」会移动整个子树；不会改变子级的终端关联。保存不执行命令。

添加终端入口

查询当前 SSH 主机的默认 tmux session，不会自动连接或创建。

SSH 主机是服务器别名；session 是查询结果里的会话名称，两者不是同一个概念。window 只在需要指定会话内部窗口时填写。

保存只写配置，不执行。入口与第一版共用；修改后已打开的终端不会重新执行指令。编辑时 ID 固定，保留原有链接和关联。

确认创建远端 session

这会在服务器启动一个新的后台 tmux session。不会关闭、重命名或删除现有 session。

删除任务 / 目录？

    删除的是侧栏任务及其记录，不会删除终端入口、关闭终端或删除远端 tmux，也不会修改原始 TODO.md / 已导出的 Markdown。当前节点未保存的编辑将丢弃。删除前会保留独立备份。

    删除终端入口？

    入口与第一版共用，删除后两边的配置都会移除。不会关闭已打开的终端，也不会删除远端 tmux、任务或记录。已有任务关联与外部 URL 会失效，可以重新关联或重新创建相同 ID。
