# Changelog

## 1.1.1 — 2026-09-21

- 接入 TerminalWorkBar 仓库，增加开发 / 稳定分支、版本校验及 Tag 自动发布流程。
- 支持带 dev / alpha / beta / rc 后缀的预发布源码包，附逐文件与整包校验。
- 仓库根目录支持直接安装，保持解压发行包的安装方式兼容。
- 配套说明网站 1.3.2，保留 1.3.1 的单次播放及滚动修复；新增仓库发布交接说明。
- 不改变个人任务、入口、SSH 配置或应用数据目录。

## 1.1.0 — 2026-09-21

- 工作记录增加“编辑”入口，保留记录 ID / 创建时间，保存独立更新时间。
- 按更新时间（旧记录回退创建时间）倒序展示；导出预览及两种 Markdown 采用同样顺序。
- 编辑复用任务库锁、revision、原子写入与修改前备份；冲突时保留草稿，不覆盖新内容。
- 可回导 Markdown 的记录元数据兼容可选 `updated` 字段；旧任务无需迁移或改写。
- 升级只更新本机侧栏程序，不改真实任务、命令、SSH config 或 V1 App。

## 1.0.0 — 2026-09-20

首个可移交的源码发行版。

- 本机 SSH config 候选别名选择，支持静态 Include；保留手动输入，不执行 Match exec。
- 多级目录与任务、独立终端关联、工作记录、搜索和折叠。
- 关联时新增 / 编辑终端，以及终端入口确认删除。
- 任务单节点 / 子树删除、影响范围预览、独立删除前备份。
- 只读 tmux 查询、明确创建语义、UTF-8 连接、远端 zsh 目标引用兼容。
- 清爽 Markdown 与保留稳定 ID 的回导格式；本机文件选择、预览和并发保护。
- 空数据安装、保留已有配置的升级流程、纯虚构示例和完整 handoff。
- 白名单打包、逐文件 SHA-256 清单及整包校验。

版本编号说明：本文件的 1.0.0 是整套源码发行版版本；V1 / V2 是两个组件的历史角色名称，不等于发布版本或任务 schema 版本。
