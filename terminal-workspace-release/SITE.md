# Terminal Workspace 中文使用说明网站

本包准确网站版本和嵌入应用版本见 `MANIFEST.json` 的 `version` 与 `application_version`；源码中由 `GUIDE_VERSION` 和 `VERSION` 管理。1.3.2 起接入 TerminalWorkBar 仓库发布。首页为原版 Sidebar 前端的可操作 demo：终端侧栏、终端入口编辑、Markdown 预览三个窗口。旧产品短片保留在 `film.html`，完整手册在 `manual.html`。这不是原生 App，不替代实际侧栏。

## 最简单的打开方式

公开在线地址：**<https://wang202111.github.io/TerminalWorkBar/>**。首次启用后由 GitHub Actions 从 `main` 自动部署；不用安装、登录或启动本地服务。在线版跟随稳定维护线，离线 ZIP 则保留发布时的内容。网站只演示合成数据，不连接真实终端。Pages 设置与维护步骤见 `reference/RELEASING.md`（源码目录中为 `RELEASING.md`）。

解压 `Terminal-Workspace-Guide-<版本>.zip`，双击里面的 `index.html`，以 1.5 倍速自动演示，可切换 2 倍或正常速度。每段只播放一遍，结束后保留结果；点击“重播演示”才重新开始。不要只复制 HTML；保留整个文件夹结构。

### 1.3.1 修复页面跳动

1.3.0 每一步都使用 `scrollIntoView` 居中控件，可能连带滚动外层网页；输入框默认聚焦也可能触发滚动。每段结束又自动重置数据、关闭弹窗并重新播放，因此页面会反复跳动，并非跳转到其他网站。

1.3.1 只在控件被遮挡时滚动 iframe 内部的文档或弹窗，演示输入聚焦不触发滚动。取消首页无限循环，结束后保留当前结果和弹窗。切换到另一窗口会开始该窗口的一次演示；手动暂停时切换仍保持暂停。独立的 `film.html` 产品短片保留原有循环行为。

无需 Python、Node.js、联网或启动应用就能阅读。页面使用系统字体和本地资源，没有远程脚本、遥测或 API 请求。外部技术参考只有明确点击时才联网打开。

## 可以在网站里做什么

首页直接复用构建时 `terminal-sidebar/static/index.html`、`style.css`、`app.js` 的产品前端，在沙箱 iframe 中运行。Mac 外框、终端输出和内存 API 为演示实现，不是原生 iTerm2 截图。与手绘替身相比，这里的侧栏按钮、表单、层级和渲染逻辑来自真正产品源码。

- “终端 + 任务侧栏”：自动展开、打开 / 复用入口，并新建演示任务。
- “终端入口编辑”：原版表单选择虚构 SSH 别名、查询模拟 tmux、选择 window，再保存演示入口。
- “Markdown 预览”：原版导出对话框切换两种格式，展开源码。
- 可以暂停后手动操作任务、入口和记录（支持修改记录、按更新时间倒序）；点入真实控件也会自动暂停，演示不抢回鼠标。手动操作之后继续自动演示会先重置虚构示例；重播 / 切换窗口 / 刷新 / 重置也会清空此次演示修改。播放结束本身不会清空。
- 创建、删除、SSH / tmux 及终端打开都只改变内存模型。演示没有真实持久备份，无法用来验证完整后端兼容性。Markdown 导入、文件读写、原生 App / URL 调用不开放。

## 保留的产品短片

点击页头“产品短片”打开 `film.html`；默认播放速度也提高到 1.5 倍，32 秒时间线实际约 21 秒。

主片有五个镜头：层级（5 秒）、关联（7.5 秒）、打开（6.5 秒）、复用（5.5 秒）、带走 Markdown（7.5 秒）。不把所有操作等长串行播放。镜头和光标、打字共享一条可拖动时间线，暂停时整个画面冻结。

下方六个卡片分别播放：层级与记录、SSH 与 tmux、打开与复用、Markdown 往返、命令与笔记、安全删除。每段约 15–17 秒，选中后在上方播放器循环；点“返回主片”恢复 32 秒片段。完整参数和异常场景请看手册；旧 18 段素材仍保留在源码库，不再默认串行播放。

自动循环，支持暂停、上一段 / 下一段、进度拖动、倍速、全屏。空格暂停，左右方向键切换功能（控件获得焦点时保留其原生按键行为）。切到后台时暂停，原本播放中的页面返回时恢复；手动暂停的页面不会自动恢复。减少动态效果偏好下默认暂停，可手动播放。

点击右上角“完整手册”才进入下面的原有教程：

- 通过 14 个章节阅读安装、首次操作、任务树、记录、终端关联、SSH / tmux、Markdown、Obsidian、删除恢复、升级迁移及 CLI。
- 播放约 30 秒的七步模拟动画：认识界面、添加任务、新建入口、保存关联、首次打开、再次定位、导出记录。支持暂停、逐步跳转、速度切换、重新播放；切到后台自动暂停，不默认自动播放。
- 搜索整个手册正文；桌面按 `/` 聚焦搜索，手机通过“目录”打开搜索。
- 在虚构任务树里展开、选择不同层级、切换模拟关联，体验首次打开、复用和连接结束。
- 比较真实导出器生成的阅读版 / 可回导 Markdown，复制或下载示例。
- 切换两种任务删除范围，观察子级上移或子树移除的示意。
- 展开排错条目，下载完整安装、交接、验证范围和示例文档。
- 使用顶部“打印 / PDF”或浏览器打印菜单。打印时展开说明条目；PDF 是阅读副本，不保留交互。

演示只存在当前页面内存中，刷新会重置。不读取你的任务 / SSH 配置、不写入本机应用、不打开真实终端，也不执行示例脚本。浏览器若不允许自动复制，会选中文本并提示手动复制。

## 网站包和应用包的区别

- `Terminal-Workspace-Guide-<网站版本>.zip`：本网站，解压后打开 HTML。
- `Terminal-Workspace-<应用版本>-macOS-source.zip`：应用源码安装包，准备环境后运行 `Install.command`。

本网站不捆绑应用包，也不包含任何个人数据。示例是可选练习材料；JSON 只用于理解结构，不能覆盖真实活动数据。修改或重打包说明网站不会修改之前发布的应用 ZIP。

## 网站维护与构建

在维护源码的 `terminal-workspace-release/` 目录中：

- `site/index.html`、`site/demo.css`、`site/demo-shell.js`：三个窗口的外框、iframe 与播放控制。
- `site/demo-backend.js`：虚构任务 / 命令库与内存 fetch 替代，不保存原始 fetch，不允许请求真实 API。未支持的端点明确拒绝。
- `site/demo-actor.js`：操作原版控件的短演示脚本；真实鼠标或键盘输入会暂停它。不是控制本机应用的自动化。
- 构建生成的 `demo-content.js`：将原版 UI 与演示后端、播放脚本装入 iframe 的 srcdoc。`product-source/` 保留原版三个前端文件用于核对，不作为演示入口。
- iframe 只授予 `allow-scripts allow-forms`，不授予同源访问、弹窗、下载或顶层导航。CSP 限制 `connect-src 'none'`、`form-action 'none'`；前端表单走 JS 的内存 API。localStorage 在这个不透明源沙箱中不可用，原版 UI 会按现有异常处理退回内存状态。
- `site/film.html`、`site/cinema.css`、`site/cinema.js`：保留的产品短片。按场景时间线驱动 DOM，不调用真实应用或系统点击。
- `heroScenes` 定义主片事件和镜头关键帧；`clipDefinitions` 定义六个功能短片，引用 `libraryScenes` 的素材。镜头格式为 `[毫秒, 横向焦点0到1, 纵向焦点0到1, 放大倍数]`。弹窗自动限幅以免裁切；手机端限制倍率；减少动态效果偏好下固定全景并默认暂停。
- `site/manual.html`：完整中文内容、结构、示意图和下载链接。
- `site/styles.css`：桌面 / 手机布局与打印样式。
- `site/app.js`：搜索、模拟任务树、复制、格式切换与删除范围示意。
- `build_guide.py`：白名单复制文档，使用同仓库的 Markdown 导出器生成合成示例，输出静态网站、ZIP 和 SHA-256。
- `SITE.md`：本文；构建后作为网站根目录 README。

在维护源码目录执行：

```bash
python3 build_guide.py --output /path/to/new-output
```

`/path/to/new-output` 是占位符，请换成你的输出目录。需要 Python 3.11+；构建器依赖相邻的 `terminal-sidebar/markdown_io.py`。网站分发包自身不包含完整应用源码或构建器。已有同名产物时拒绝覆盖，以免改动已发布文件。

完整预览请使用构建输出目录；直接打开源码首页缺少生成的 `demo-content.js`。构建器还需要相邻的 `terminal-sidebar/static/`。更新产品 UI 后重新构建 demo，再检查控件选择器与内存 API 是否适配，尤其是执行触发点、导入覆盖语义和迁移边界。

## 放到自己的网页服务器

将构建输出的整个网站目录放到静态托管目录即可，入口为 `index.html`；所有内部引用使用相对路径。无需数据库、后端、域名绑定代码或用户账户。

如仅想本机预览，可在网站目录运行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8765/`。该服务只用于文档，不是 Sidebar 私有服务。结束后 Ctrl+C 停止；如端口被占用请换一个。

公开发布时只上传此网站目录，绝不要把真实工作目录、SSH 文件、用户配置、日志、备份或带令牌的服务地址加入其中。没有替你部署公共域名。
