# 验证范围与复测说明

## 1.1.0 工作记录更新

使用临时任务库验证：保留记录 ID / created、生成 updated、编辑和新增后倒序、旧记录兼容、修改前备份、过期 revision、错误任务 / 记录 ID、空白 / 超长 / NUL 内容拒绝且不写库。验证可回导 Markdown 保留 updated、Markdown 修改正文更新时间、新库导入，以及排序读取不改动文件。

真实前端连接隔离本机测试服务（不连接用户数据库）验证：编辑保存后置顶、取消、HTML 文本安全渲染、并发更新拒绝并保留草稿、新记录置顶、导出预览顺序。Chromium 无 JavaScript 错误。发布更新不使用用户任务进行写入或删除测试。

## 验证环境

开发验证使用 macOS、Python 3.13、iTerm2 3.5.14，以及固定依赖 iterm2 2.24 / websockets 17.1 / protobuf 7.36.2。浏览器流程使用隔离的无头 Chromium；原生 Toolbelt 注册通过 iTerm2 Python API 验证。

这是验证环境描述，不代表已验证所有满足最低要求的系统。源码包会在用户机器编译当前架构，未交付 universal binary / 公证签名 App。

## 已验证的功能边界

- Python 模块编译、网页 JavaScript 语法检查。
- 任务树迁移、父级有效性、循环拒绝、深层遍历、稳定 ID 与记录保留。
- 节点删除的确认 / scope / revision / ID 校验、子级上移、子树删除、空列表、独立备份、1500 级子树。
- 终端编辑的 ID / cwd / 原 argv 保留、过期配置拒绝、删除确认、命令与任务互不误删。
- 关联窗口内新增入口后选中，节点草稿保持；删除入口后的失效关联可重新配置。
- tmux 普通 / 自动创建 / window 脚本、旧新向导识别、zsh 引用、UTF-8 选项。
- SSH config 多别名、静态 Include / glob / 循环、引号 / 等号 / 注释、模式排除、去重、不执行 Match exec。
- 新安装的空 TODO / 配置，以及保留既有设置和文档内容的升级路径。
- Markdown 稳定 ID 往返、特殊字符、多行记录、部分导入保留、未知命令警告、过期预览拒绝。
- 阅读版与回导版选择、预览、安全渲染、导出不覆盖、取消保存不写文件。
- 本机 API 令牌保护，修改源码后运行副本内容一致性。

破坏性用例仅使用临时 Store、临时命令文件和隔离浏览器。真实用户任务、SSH 文件和远端会话不能用来做删除测试。

## 不夸大的验证边界

- 原生保存对话框的 AppleScript 通过编译检查；保存 / 取消 / 已存在文件行为使用替代选路器与临时文件验证，没有自动操作用户保存窗口。
- 完整“全新 macOS → 安装依赖 → 系统授权”的流程不能由当前机器上的检查替代。安装脚本提供 `--check`，首次机器仍需用户安装依赖并授权。
- 没有逐个连接所有 SSH 候选别名；候选选择不是连接测试。
- 没有验证所有远端 shell、tmux 版本、自定义 socket 或密码认证组合。

## 收包后建议复测

1. 校验 ZIP 的 `.sha256`，并用 `MANIFEST.json` 校验每个解压文件。
2. `python3 install.py --check`；再按 INSTALL 安装。
3. 新增一个仅打印文字的本地测试入口，不使用真实生产命令。
4. 按 examples/README 手动导入虚构树，测试展开、编辑、记录、两种导出和预览导入。
5. 测试“删除本级保留子级”和“整棵删除”，核对独立备份。
6. 用可安全访问的测试主机验证别名选择、只读查询以及明确连接；不要在生产会话里测试创建 / 删除。
7. 变更 API 或存储逻辑后，重新检查两个 revision、原子写入和保持 V1 行为的边界。

本源码树原先没有常驻自动化测试套件；发行前使用了临时 Python / Chromium 验证脚本。后续建立 CI 时请使用合成配置，不要依赖维护者的真实 HOME、SSH 或 iTerm 会话。
